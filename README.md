# 🤖 Telegram Business Bot for Lead Generation

Асинхронный Telegram-бот для приёма заявок, записи клиентов и автоматизации первичных продаж. Предназначен для малого бизнеса, фрилансеров и сервисных услуг.

## 🛠 Стек

* **Python 3.10+**
* **Aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
* **Aiosqlite** — асинхронная работа с базой данных SQLite
* **Python-dotenv** — управление конфигурацией и секретами

## 🚀 Основные возможности

* **Пошаговый сбор данных (FSM):** Интерактивный опросник для оформления заявки (Имя, Телефон, Описание задачи).
* **Сбор контактов:** Быстрая отправка номера телефона через встроенную кнопку Telegram.
* **Уведомления администратору:** Мгновенная пересылка созданной заявки в личные сообщения менеджеру/админу.
* **База данных SQLite:** Автоматическая регистрация пользователей и сохранение истории всех заявок.
* **Поддержка Прокси:** Готовая интеграция `AiohttpSession` для работы в условиях сетевых ограничений.
